Buscador de leyes mexicanas para abogados (backend Node.js/Express). Ver `CLAUDE.md` para el
detalle de arquitectura.

## Cómo correrlo

```
npm install
npm run migrar-datos
npm run crear-usuario -- tu@correo.com "unaContraseñaSegura" admin 24
npm start
```

Abre `http://localhost:3000`.
